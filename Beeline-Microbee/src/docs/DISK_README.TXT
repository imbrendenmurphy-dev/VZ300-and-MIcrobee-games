BEELINE - Microbee Premium Plus 3D racing engine tests
VIBED BY BPM 2026

Boot this disk, then type one of these at the A> prompt:

RACE    the pseudo-3D road prototype
        M / SPACE / cursor up   accelerate
        N / cursor down         brake
        Z X  (or , .)           steer
        C                       change colour theme
        FPS is shown on the top line.

BENCH   video RAM speed test. Wait about 8 seconds for all
        seven numbers, then photograph the screen.
        Emulator figures: 591 599 474 472 472 973 599

CUBE    solid polygon test (dither-shaded spinning cube).
        FPS shown top left.

Each program takes over the machine. Press RESET to leave.
