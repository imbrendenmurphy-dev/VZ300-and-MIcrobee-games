BEELINE - a 3D road race for the Microbee Premium Plus
VIBED BY BPM 2026

Boot this disk, then type BEELINE at the A> prompt.
(BEELINE.COM loads BEELINE.DAT from the same disk.)

THE RACE
  Five legs, point to point, against 19 rivals and the clock:
    1 GREEN VALLEY   2 RED CENTRE   3 SNOWY RANGE
    4 COAST AT DUSK  5 NIGHT RUN
  Reach each checkpoint before the time runs out - every
  checkpoint adds time.  You start last of 20: overtake rivals to
  move up (POS on the top line).  Bumping a car or running off the
  road only costs speed.  Finish the fifth leg for a time bonus.

KEYS
  SPACE or M      start / accelerate
  N               brake
  Z X  (or , .)   steer   (cursor keys work too)
  P               pause
  S               music on/off
  ESC             back to the title screen

The title screen shows the race on autopilot and the best scores.

ALSO ON THIS DISK
  BENCH   video RAM speed test (seven numbers after ~8 seconds)
  CUBE    solid polygon test (dither-shaded spinning cube)

Each program takes over the machine. Press RESET to leave.
