BUNYIP - a first-person adventure for the Microbee Premium Plus
VIBED BY BPM 2026                              (work in progress)

Needs a Premium Plus with 1MB RAM. Boot this disk, then type
BUNYIP at the A> prompt. The loader checks the machine, loads the
game files into RAM, then the game takes over (RESET to leave).

Four zones: SANDSTONE GALLERY, MANGROVE TUNNELS, OPAL MINES and
THE BUNYIP'S DEEP. Find the keys, swing the lever gates, beat each
zone's guardian, then reach the exit.

  Cursor keys / W A S D   walk and turn
  Z  X                    sidestep
  SPACE                   zap
  E or RETURN             use: doors, levers, secret walls
  M                       map of what you have seen
  P                       pause
  C                       colour / amber mono (also on the title)

Creatures: redbacks, flying foxes, yowies, cane toads, drop bears,
min min lights, saltwater crocs and the bunyip itself.

Things to find: keys, meat pies (health), zapper charges, opals
(score) and the Southern Cross (double zaps for half a minute).
Smash urns for what is inside. Shoot TNT from a distance. Keep clear
of bull ant nests and boiling mud.

The sprites are made at start-up and while each zone's story is
shown, so the first screens take a few seconds.
