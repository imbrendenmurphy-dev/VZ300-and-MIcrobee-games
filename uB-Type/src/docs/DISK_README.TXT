uB-TYPE for the Microbee Premium Plus (1MB)
===========================================

Boot this disk. At the A> prompt type

    UBTYPE

and press RETURN. The loader fills the RAM banks and starts the game.

Then choose your monitor: C for colour, M for monochrome.

Controls
  Q A O P or the cursor keys   move
  SPACE                        fire - hold to charge the beam
  M or Z                       launch / recall the pod
  H                            pause (X while paused ends the game)
  ESC or RETURN                back to the title
  T on the title screen        trainer mode (no high scores)
  A joystick on the parallel port works too.

Converted from VZ-TYPE for the VZ300.
