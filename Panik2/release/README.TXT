PANIK 2 - "DIG DEEPER!"                                    version 1.1
for the Dick Smith VZ300 / VZ200 with the BennVenn SD loader + 128K RAM
VIBED BY BPM 2026

The sequel to the VZ game PANIK (VZ-PANIC).

TO PLAY:  copy PANIK2.VZ to the SD card and run it from the BennVenn
          menu. It loads at $8000 and starts by itself.

KEYS:     M left   , right   Q up a ladder   A down a ladder
          SPACE (or Z, or fire): dig a hole / bash a trapped alien
          Either joystick on the VZ joystick interface works too.
          1-4 on the title screen: start at world 1-4
          P pause (X quits while paused)
          S sound: music+effects / effects only / off

HOW:      Dig a hole in the girder in front of you. An alien walks in
          and gets stuck - bash it and it drops through the floor.
          GRUBS die from a 1-floor drop, BRUTES need 2 floors, KINGS 3:
          dig holes above each other for longer drops (more points).
          Drop one alien onto another for 1000. Leave one in a hole too
          long and it climbs out angry. Watch the oxygen bar!

          16 stages in 4 worlds, a GEM DIG bonus round after each
          world, a coffee break, an ending, then a faster lap 2.
          Extra digger at 20,000 and every 40,000 after.

If the screen says PANIK 2 NEEDS THE BENNVENN SD LOADER WITH 128K RAM,
the game couldn't find the expansion's RAM at $4000-$67FF.
