PHASE 2 COMBAT TEST

This disk boots to the CP/M prompt. Type  REDBACK  to start.

  Joystick or keys: Q/UP = up, A/DOWN = down, O/LEFT = left,
  P/RIGHT = right, SPACE or joystick button = fire (hold for
  auto-fire).  ESC returns to CP/M.

Shoot the drone waves (100) and interceptors (250). Interceptors
chase your height and shoot back. 3 ships; GAME OVER restarts
after 5 seconds.

Display: 40 x 25 cells (8 x 10), PAL 50 Hz, one-pixel smooth scrolling.
